# 油品价格维护

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据默认保存在浏览器localStorage中，方便后续扩展接口、权限、图表或地图能力。

## 调价记录与默认价恢复

- **保存调价**：在左侧表单填写油品、挂牌价、操作员、生效日期和备注，提交后生成一条「生效中」记录并排在历史最前。
- **历史筛选**：支持按油品（92/95/98 号汽油、柴油）和状态（生效中/待确认/已回退）组合筛选；无匹配时提示调整筛选条件，没有任何记录时提示提交首次调价。
- **恢复默认价**：每张油品的最新记录可一键恢复到默认挂牌价（默认价见表单下方列表），系统自动新增一条「已回退」记录，备注形如 `恢复默认挂牌价：¥8.50 → ¥8.05`。
- **防重复恢复**：已是默认价的最新记录按钮禁用并显示「已是默认价」；更早的历史记录显示「历史记录」且不可再恢复，store 层同样会拒绝，不会产生重复回退记录。
- **状态终态**：状态链为 生效中 → 待确认 → 已回退。仅每种油品的**最新一条记录**可流转状态，历史记录按钮禁用且 store 层拒绝修改；「已回退」是终态，也不会再变回生效中。
- **持久化**：所有记录写入 localStorage（key：`dfwlfront-9-price`），刷新页面后仍保留。

## 验证

- `npm run verify:logic`：对 store 做 17 组 Node 层断言（新增、油品/状态筛选、恢复默认价、重复恢复防护、历史记录禁流转、已回退终态、持久化、空数据与坏数据容错）。
- `npm run dev` 后运行 `npm run verify:e2e`：Playwright 浏览器端到端验证真实点击、刷新持久化和空数据提示。
